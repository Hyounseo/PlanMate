# 일정관리 필드 정리

## Schedule

| 필드명 | 설명 |
|---|---|
| schedule_id | 일정 ID |
| user_id | 회원 ID |
| subject_id | 과목 ID |
| title | 일정 제목 |
| schedule_date | 공부 날짜 |
| start_time | 시작 시간 |
| end_time | 종료 시간 |
| memo | 메모 |
| status | 일정 상태 |
| created_at | 생성일 |
| updated_at | 수정일 |

## Subject

| 필드명 | 설명 |
|---|---|
| subject_id | 과목 ID |
| user_id | 회원 ID |
| subject_name | 과목명 |
| color | 과목 색상 |
| target_time | 목표 공부 시간 |
| created_at | 생성일 |
